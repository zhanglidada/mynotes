# 考场速查表：论题 × 素材匹配（修订版）

> 用途：考场上拿到 4 个论题后，30 秒内判断"选哪题、用哪个素材"。
> 你的真实素材 = 数据库执行引擎（PL/SQL 引擎、批量化火山模型）+ 分布式（MP/SP/BP）+ raft 高可用 + SIMD 向量化。
> **修订说明**：信创方向已从"能套"划到"错位/放弃"——因信创"信息系统适配"论题要的是"兼容/迁移/选型"（架构层面），而你的素材是"锁/SIMD"（数据库内核层面），两者错位。

---

## 一、30 秒判断流程

1. **先看子问题，别看标题**——子问题限定的"论述角度"才是判断依据；
2. **判断方向**（架构风格 / 质量属性 / 系统类型 / 新技术）；
3. **对照下表**，判断"能套 / 不能套"；
4. **选"能套"里你最熟的那个**，果断开写；"不能套"的题，一秒都别纠结。

## 四、核心判断原则（记牢三条）

1. **宽泛型论题**（子问题不限定角度，如"论系统性能优化"）→ 数据库素材能深入写，✅ 套；
2. **限定角度型论题**（子问题明确列举"缓存/异步/限流/服务拆分"等）→ 数据库素材套不上，❌ 弃；
3. **你的覆盖盲区 = 架构风格 + 应用系统 + AI 应用 + 信创（信息系统适配）**——这四类论题出现时，无匹配素材，认输即可，别硬编。

## 附：为什么信创被划掉（备查）

信创论题「信息系统架构设计与适配」要写的是：
- 兼容性适配（存量系统怎么在国产平台"能跑"）
- 迁移策略（怎么"平滑搬过去"）
- 技术栈选型（为什么选鲲鹏/麒麟/国产数据库）

而你真实有的是：锁竞争、SIMD、NUMA——这些是**数据库内核性能优化细节**，属于"数据库CPU适配"（窄题、软考几乎不考），不属于"信息系统适配"（宽题、软考会考）。

**硬写锁/SIMD = 视角错位（像内核研发，不像系统架构师）；改写兼容/迁移 = 编造。** 两条路都不通，故放弃。
